## Оружие

---

### Оружие и его свойства.

---

**Термины:**
**натур** - натуральное значение куба
**ПЛ** - Плоский урон ( базовый урон оружия )
**СМ** - Смертоносность ( пороговое значение которое должен пройти куб Хаоса )

**Шаблон оружия:**

- **Точность:** База + мод профильной характеристики ( ловкость \ сила )
  \- База - точность и кучность самого оружия
  \- профильная характеристика - характеристика, от которой зависит точность оружия. ( ловкость \ сила )
- **Урон:** База / Смертоносность (порог Хаоса)
  \- База - Плоское значение урона оружия
  \- Смертоносность - пороговое значение, ниже или равно которому требуется выкинуть натуральный куб Хаоса, для нанесения полного урона. Если куб Хаоса больше Смертоносности, наносится только половина плоского урона, округлённая в меньшую сторону.
- **Подавление:** Может ли оружие подавлять и на сколько?
  \- оружие с одиночным режимом стрельбы имеет слабое подавление обычно: 0-1
  \- Автоматическое оружие имеет повышенное подавление.
- **Дистанция:** Метры (далее +1 СП)
  \- Дистанция - это эффективная дистанция оружия, на протяжении которого он не будет получать дополнительный СП.
- **Надежность:** Тип производства - влияет на Клин
  \- Кустарное: клин на 9 и 10.
  \- Архаичное: клин на 10.
  \- Передовое: клин на 10. Первый клин в боевой сцене - игнорируется.
  \- Экзотическое: Вместо клина - выстрел не осуществляется. ( предохранители )
- **Боезапас:** Кинетика - легкий боеприпас, средний, тяжелый. Экзотика - энергия, кислота, температура.
  \- Действие атака расходует боезапас. Он отражен в виде = "жетонов атаки".
  \- Магазины - полностью восполняют жетоны атаки у оружия, при совершении действия "перезарядка".
- **Теги:** Отражает специфику каждого конкретного образца оружия

### Образцы вооружения

---

Типы оружия:
Оружие разделяется на функциональные классы, которые определяют геймплей с ним. Каждое оружие - дает разные возможности и геймплей.

| Оружие      | Особое оружие       | Экзотика             | Холодное        |
| ----------- | ------------------- | -------------------- | --------------- |
| Дробовик    | Плазменная винтовка | Инженерный мультитул | НОЖ             |
| Штурмовая В | Лазерная винтовка   | Буровой лазер        | электро дубинка |
| Пулемёт     | Электро пистолет    |                      |                 |
| П. Пулемёт  | Ручной гранатомёт   |                      |                 |
| Пистолет    | Огнемёт             |                      |                 |
Философия:
у меня есть 4 типа производства: кустарное, архаичное, передовое и экзотическое.
Требуется среднее распределение в районе архаичного и передового.
Крайние позиции это экзотика и кустарное.

Кустарное - мощное, не стабильное, как правило имеет низкую точность.
Архаичное - рабочая лошадка, но без излишеств.
Передовое - имеет больше наворотов по тегам. Так же имеет лучше точность и урон.
Экзотика - это штучные образцы, выходящие за рамки. Как правило это или регламентированное оружие, или одноразовое ( потратил заряд и все ) или что-то не типичное ( например огнемёт. у которого по сути мини механика работы )

Подавление - это следствие от нескольких вводных: скорострельность, калибр и точность.

### Медикаменты

---

Применение медикаментов в боевой обстановке, стоит действие или может быть бесплатным в ход персонажа.
Некоторые медицинские препараты используются во время короткого или длительного отдыха.

**Кровотечение**

- **Бинт** ( действие ) - устраняет "1 Незначительное" кровотечение.
- **Жгут** ( действие ) - устраняет "3 Артериальное" кровотечения в руках и ногах. Нельзя применить к голове и торсу.
  _( если жгут находится на конечности дольше 1 игрового часа, персонаж получает -1 мод к броскам, где задействует обе руки. )_
- **Гемостатик** ( действие ) - устраняет "3 Артериальное" в голове и торсе и Серьёзное кровотечение.
- **Гемопак** ( короткий\ длительный отдых ) - восстанавливает 2к8 единиц крови.

**Кости и конечности**

- **Шина** ( действие ) - устраняет перелом
- **Хирургический набор** ( действие ) - Восстанавливает критически повреждённую часть тела.

**Тело и Кожа**

- **Пантенол** ( короткий\ длительный отдых ) - противоожоговый гель устраняет эффект ожога, до длительного отдыха или получения нового ожога в области.
- **Йод** ( действие ) - защитная мера, организм персонажа снабжается йодом, что позволяет игнорировать 1к6 жетонов облучения до длительного отдыха.
- **Антирад** ( короткий\ длительный отдых ) - сильный регенеративный препарат с йодом, устраняет 2к4 жетонов облучения радиацией.

**Стимуляторы**

- **Стабилизатор** ( бесплатно ) - стабилизирует персонажа в терминальной стадии или нокаутированном состоянии и дает ему 5 единиц крови.

- **Эпипен** ( бесплатно )- Адреналин, на **1к4 раундов** игнорируются все штрафы. После окончания действия, персонаж получает 2 жетон истощения. Следующее использование до длительного отдыха - удваивает прошлое количество жетонов истощение.

- **Налаксон** ( действие ) - Антидот снимает все эффекты интоксикации. Блокирует получение новых эффектов от стимуляторов и токсинов до длительного отдыха.

- **Морфий** ( действие ) - Персонаж игнорирует ВСЕ негативные эффекты от повреждения конечностей. В первый ход боевого столкновения, персонаж имеет только манёвр. Так же снимает 4 истощения. Повторное применение до длительного отдыха провоцирует психоз.

- **β-блокатор** ( действие ) - Устраняет накопленный стресс и блокирует его накопление до короткого отдыха. В первый ход боевого столкновения, персонаж имеет только манёвр. Броски рассудка и эмпатии с помехой.

- **Пирацетам** ( действие ) - нейростимулятор, следующие 3 раунда, дисциплина персонажа считается полностью очищенной а любое количество стресса и истощения - игнорируется. После окончания действия, персонаж берет 1 жетон истощения. Повторное применение до длительного отдыха провоцирует психоз.

- **Био-Гель** ( длительный отдых ) - Полностью восстанавливает все тело, устраняя все повреждения.
